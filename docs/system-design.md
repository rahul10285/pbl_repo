System Modules
1. User Authentication Module
Handles user signup and login functionality.
Validates credentials using file-based storage and maintains active session information.

2. Clothing Item Management Module
Allows users to:

Add clothing items

Specify size, category, and condition

Store owner information

Persist data using file handling

3. Search and Matching Module
Enables users to:

View available clothes

Search by size

Validate compatibility between users

Implements basic matching logic based on size comparison.

4. Swap Request Module
Allows users to request a swap for a selected clothing item.
Includes validation to prevent swapping own item.

5. Future Optimization Module (Planned)
Planned enhancements include:

Location-based filtering

Graph-based multi-party swap detection

Weighted scoring and ranking system

Karma-based reputation system
