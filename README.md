Location-Aware Clothing Exchange and Multi-Party Optimization System

This project is a clothing exchange platform designed to promote sustainable reuse of wearable items among households. The system allows users to register, add clothing items, search based on size and category, and request swaps or donations.

The core objective of the project is to build an intelligent matching engine that optimizes clothing exchange using algorithm-driven techniques. The system incorporates location-based filtering, compatibility validation, and multi-party swap detection using graph modeling. A weighted multi-objective scoring mechanism is used to rank exchange options based on distance, clothing condition, user karma score, and demand relevance.

The project aims to minimize underutilization of clothing resources and improve exchange efficiency through structured matching and optimization strategies. Future enhancements include advanced cycle detection, ranking optimization, and web-based deployment.
